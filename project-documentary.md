## The Origin Story

In the quiet corners of local machines, away from cloud dependencies and privacy concerns, a new kind of intelligence emerged. Not a chatbot that waits for prompts. Not a tool that needs constant supervision. But an **autonomous agent** — one that thinks, plans, executes, and learns. One that works in the shadows, silently transforming ideas into reality.

This is **GPTLoop**: a production-grade, autonomous AI agent system designed to operate locally on the user's machine. Currently focused on coding, but built with a grander vision — to become a **general-purpose autonomous agent** capable of handling any domain, any task, any challenge.

---

## Core Philosophy

### Local-First Sovereignty
The agent lives on the user's machine. No cloud. No remote containers. No data leakage. Everything — the memory, the knowledge, the work — stays local. Privacy isn't a feature; it's the foundation.

### Autonomous by Design
This isn't a chatbot waiting for your next message. It's an agent that:
- **Reasons step by step** using the ReAct pattern (Thought → Action → Observation → repeat)
- **Works independently** until the task is complete or a genuine blocker appears
- **Delegates intelligently** to specialized sub-agents when parallelism or expertise is needed
- **Maintains persistent memory** across sessions, learning and evolving over time
- **Schedules itself** to perform tasks on cron schedules, even when the browser is closed

### Multi-Agent Architecture
One agent is powerful. A team is unstoppable. The system supports:
- **Main Agent**: The primary autonomous worker
- **Sub-agents**: Specialized delegates (debugger, code reviewer, deep researcher, etc.)
- **Multi-agent teams**: Head agent coordinating multiple member agents
- **CEO agent**: A meta-coordinator controlling multiple team leaders
- **Custom agents**: User-created agents with their own identity and tools

### Production-Grade Reliability
This isn't a demo. It's built for production:
- SQLite-backed persistence (no data loss)
- Checkpoint system (undo/redo any work)
- Comprehensive error handling and recovery
- Streaming-first architecture (real-time feedback)
- Daemon mode (runs as a background service)

Today, it's a coding agent. Tomorrow, it's **anything**.

The architecture is domain-agnostic:
- The agent runtime doesn't care if it's writing code, analyzing data, managing workflows, or researching topics
- Skills can be created for any domain
- Sub-agents can specialize in anything
- The memory system learns and adapts to any context
- The scheduling system automates any recurring task

The goal: **A truly autonomous general-purpose agent** that:
- Understands any task
- Plans the approach
- Executes autonomously
- Learns from experience
- Improves over time
- Works quietly in the background
- Respects user privacy

- Reliability over hype
- Correctness over speed
- Quality over quantity

### Self-Evolving
The agent maintains its own memory:
- **MEMORY.md**: Long-term durable facts
- **SOUL.md**: Evolving persona and principles

It literally writes its own identity and learns from every interaction.

## Naming Direction

The name should convey:
1. **Autonomy** — it works independently
2. **Intelligence** — it thinks and learns
3. **Reliability** — it's production-grade
4. **Generality** — it's not limited to one domain
5. **Local/Privacy** — it respects sovereignty
6. **Quiet power** — efficient, not flashy

### Naming Styles to Consider

**Mythological/Classical**
- Names from mythology (gods, titans, creatures) that convey power, wisdom, or autonomy
- Examples: Hermes (messenger), Athena (wisdom), Argus (all-seeing)

**Nature/Animals**
- Animals or natural phenomena that embody autonomy, intelligence, or quiet power
- Examples: Falcon (vision), Wolf (pack intelligence), Storm (power)

**Abstract/Conceptual**
- Names that evoke concepts like autonomy, intelligence, universality
- Examples: Nexus, Core, Flux, Prism

**Descriptive**
- Names that describe what it does or how it works
- Examples: AutoMind, LocalAgent, SovereignAI

**Evocative**
- Names that evoke a feeling or quality
- Examples: Silent, Quiet, Steady, Reliable
